Let's see the current definition of CombatStats:

```python
@dataclass
class CombatStats:
    max_hp: int = 20
    hp: int = 20
    toughness: str = "average"
...
```

If we turn them into properties, `dataclass` won't like it since it expects fields. We might need to override `__init__` or use `@property`.

Actually, wait, if we use `@property`, `dataclass` will not include them in the `__init__` which is fine, but they won't be serialized or initialized automatically.

Let's look at `Animal` (in `entities/animal.py`):
```python
        self.combat.max_hp = animal_def.get("max_hp", 10) // 2
        self.combat.hp = new_animal.combat.max_hp
```
If we make `hp` and `max_hp` properties, doing `self.combat.max_hp = 10` will need a setter that appropriately scales the `body_parts_max_hp`.

For example:
```python
@dataclass
class CombatStats:
    body_parts_hp: dict = field(default_factory=lambda: {"head": 5, "torso": 10, "left_arm": 5, "right_arm": 5, "left_leg": 5, "right_leg": 5})
    body_parts_max_hp: dict = field(default_factory=lambda: {"head": 5, "torso": 10, "left_arm": 5, "right_arm": 5, "left_leg": 5, "right_leg": 5})
    toughness: str = "average"
    is_hostile_to_player: bool = False
    combat_behavior: str = "defensive"
    base_attack_name: str = "fists"
    base_attack_damage_dice: str = "1d3"
    attack_range: int = 1
    target_entity_id: int | None = None

    @property
    def max_hp(self):
        return sum(self.body_parts_max_hp.values())

    @max_hp.setter
    def max_hp(self, value):
        # simple proportional scaling
        current_max = self.max_hp
        if current_max == 0:
            return
        ratio = value / current_max
        for part in self.body_parts_max_hp:
            self.body_parts_max_hp[part] = max(1, int(self.body_parts_max_hp[part] * ratio))
        # adjusting remainder
        diff = value - sum(self.body_parts_max_hp.values())
        if diff != 0:
            self.body_parts_max_hp["torso"] += diff

    @property
    def hp(self):
        return sum(self.body_parts_hp.values())

    @hp.setter
    def hp(self, value):
        # We also need hp setter since code uses `self.combat.hp -= damage` or `self.combat.hp = max_hp`.
        # When hp is set, we could scale proportionally based on body_parts_max_hp.
        current_hp = self.hp
        if value <= 0:
            for part in self.body_parts_hp:
                self.body_parts_hp[part] = 0
            return

        # typically, hp is set to max_hp
        if value == self.max_hp:
            self.body_parts_hp = self.body_parts_max_hp.copy()
            return

        # otherwise, scale proportionally?
        ratio = value / current_hp if current_hp > 0 else 0
        for part in self.body_parts_hp:
            self.body_parts_hp[part] = int(self.body_parts_hp[part] * ratio)

        diff = value - sum(self.body_parts_hp.values())
        if diff != 0:
            self.body_parts_hp["torso"] += diff
```
