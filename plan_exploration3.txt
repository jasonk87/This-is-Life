If we do this, `max_hp` and `hp` are properties. Any code doing `CombatStats(max_hp=15, hp=15)` will fail because `max_hp` and `hp` are no longer fields!

Wait, wait. Python `dataclasses` don't allow `InitVar` to be easily mixed with properties without an `__post_init__` to handle initial values.
We could just keep `hp` and `max_hp` as properties, and handle initial values in `__init__`. Since `entities/base.py` uses `@dataclass`, maybe we can just use `InitVar` or define a custom `__init__` instead.
But `@dataclass` writes `__init__` for us. If we define properties, `dataclass` ignores them. If there's `CombatStats(max_hp=15, hp=15)` calls in the codebase, we'll get a `TypeError`!
