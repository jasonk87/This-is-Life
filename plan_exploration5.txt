Let's modify `take_damage` in `entities/base.py` for `NPC`.

Wait, if `torso` reaches 0, does the NPC die? "hp and max_hp act as aggregate properties". So if total `hp <= 0`, they die.
Total HP = sum(body_parts_hp.values()). If all parts reach 0, or just sum reaches 0, they die.
If total `self.combat.hp <= 0`, they die. Since `effective_damage` is subtracted and spilled over, total HP decreases exactly by `effective_damage` unless `torso` goes below 0 (meaning they lost more HP than available in that part and torso, but wait... if hit in leg, and spillover to torso, total HP decreases by `effective_damage`. If torso also goes below 0, does it spill to head?
Let's just subtract from total `self.combat.hp` using property setter, and also distribute damage to body parts?
If we do:
```python
        self.combat.hp -= effective_damage
```
Wait, if `hp` is an aggregate property `sum(body_parts_hp.values())`, setting `hp -= effective_damage` will call the `hp` setter, which scales ALL body parts proportionally! That's NOT localized damage!
Ah! The `hp.setter` should only be used when setting to a specific value like `max_hp` (for healing/init). For taking damage, we should NOT use `self.combat.hp -= effective_damage`. Instead, we should subtract from a specific body part, and the `hp` property will reflect the sum!

So instead of `self.combat.hp -= effective_damage`, we do:
```python
        # In NPC.take_damage
        effective_damage = max(0, amount - total_defense_bonus)

        hit_part = random.choice(list(self.combat.body_parts_hp.keys()))
        self.combat.body_parts_hp[hit_part] -= effective_damage
        if self.combat.body_parts_hp[hit_part] < 0:
            spillover = -self.combat.body_parts_hp[hit_part]
            self.combat.body_parts_hp[hit_part] = 0
            if hit_part != "torso":
                self.combat.body_parts_hp["torso"] -= spillover
                if self.combat.body_parts_hp["torso"] < 0:
                    self.combat.body_parts_hp["torso"] = 0
                    # if torso is dead, maybe spill to head, or just let them be dead if total hp is <= 0

        # Note: If effective_damage is massive, they could still have >0 hp in other parts but 0 in torso and hit_part.
        # But wait, if they have 0 hp overall, they die.
        if self.combat.body_parts_hp.get("left_leg", 1) <= 0 or self.combat.body_parts_hp.get("right_leg", 1) <= 0:
            if "broken_leg" not in self.physical.status_effects:
                self.physical.status_effects.append("broken_leg")

        if self.combat.hp <= 0:
            # We must make sure hp is 0
            for part in self.combat.body_parts_hp:
                self.combat.body_parts_hp[part] = 0
            self.physical.is_dead = True
            return True
```
But wait, if total `hp` is the sum, and `spillover` is lost if `torso` < 0, then `effective_damage` might not reduce total `hp` by `effective_damage`.
To ensure total HP decreases exactly by `effective_damage` (until it hits 0), we can distribute the remaining damage to other parts if `torso` < 0.
```python
        remaining_damage = effective_damage
        hit_part = random.choice(list(self.combat.body_parts_hp.keys()))

        if self.combat.body_parts_hp[hit_part] >= remaining_damage:
            self.combat.body_parts_hp[hit_part] -= remaining_damage
            remaining_damage = 0
        else:
            remaining_damage -= self.combat.body_parts_hp[hit_part]
            self.combat.body_parts_hp[hit_part] = 0

            # Spillover
            for part in ["torso", "head", "left_arm", "right_arm", "left_leg", "right_leg"]:
                if remaining_damage <= 0:
                    break
                if self.combat.body_parts_hp[part] > 0:
                    if self.combat.body_parts_hp[part] >= remaining_damage:
                        self.combat.body_parts_hp[part] -= remaining_damage
                        remaining_damage = 0
                    else:
                        remaining_damage -= self.combat.body_parts_hp[part]
                        self.combat.body_parts_hp[part] = 0
```
This guarantees that exactly `effective_damage` is removed from `body_parts_hp`, ensuring `self.combat.hp` drops by exactly `effective_damage`.
